About This Project

This website is a multi-stage web development project for IT 3203. It presents research on phishing and social engineering using hand-written HTML, a single external CSS file, and vanilla JavaScript for the interactive self-assessment quiz. The site demonstrates semantic HTML, a consistent navigation menu, CSS grid and flexbox layouts, multiple selector types, interactive hover states, timed quiz logic, and per-question scoring — all without the use of site builders or code generators.

In Milestone 2, a ten-question self-assessment quiz was added to the site. The quiz enforces a 10-minute time limit, calculates the user's score and pass/fail result, displays the correct answer for every question, records time spent, and provides a full reset option so users can retake the quiz.
