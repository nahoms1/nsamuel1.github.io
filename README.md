# Phishing & Social Engineering — IT 3203 Milestone #1

A static website presenting research on phishing and social engineering,
built with hand-written HTML5 and a single external CSS file.

## Pages
- `index.html` — Homepage (abstract, key terms, table of contents)
- `how-phishing-works.html` — Topic page 1
- `defenses.html` — Topic page 2
- `key-concepts.html` — Seven key concepts
- `references.html` — References and learning resources
- `about.html` — About the author and project

## Technologies
- HTML5 (semantic elements)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- GitHub Pages for deployment

## Requirements Met
- Six pages with a consistent main menu
- Headings, lists, images, tables
- One external CSS file
- Three selector types: element, class, ID
- Grid layout (main menu) and Flexbox layout (content, profile)
- Hover effects, padding, margins, borders, colors, fonts
- Footer note linking to the class website
- Code comments throughout
