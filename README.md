# Phishing & Social Engineering — IT 3203 (Milestones 1 & 2)

A static website presenting research on phishing and social engineering, built with hand-written HTML5, a single external CSS file, and vanilla JavaScript for an interactive self-assessment quiz.

## Live Site
(https://nahoms1.github.io/nsamuel1.github.io/)

## Pages
- `index.html` — Homepage (abstract, key terms, table of contents)
- `how-phishing-works.html` — Topic page 1 (attack anatomy, variants)
- `defenses.html` — Topic page 2 (technical + human controls)
- `key-concepts.html` — Nine key concepts
- `references.html` — References and learning resources
- `quiz.html` — Self-assessment quiz (Milestone 2)
- `about.html` — About the author and project

## Milestone 2 Features
- Ten-question quiz on `quiz.html`:
  - 4 single-choice MCQs (radio buttons)
  - 1 multi-select MCQ (checkboxes, 3 correct answers)
  - 2 fill-in-the-blank (text inputs)
  - 3 additional single-choice MCQs
- 10-minute countdown timer with auto-submit at 0:00
- Instant scoring: pass/fail (70% threshold), total score, per-question correctness, and correct answer
- Time spent displayed after submission
- Color-coded results (green = pass/correct, red = fail/incorrect)
- Retake button fully resets inputs, results, and timer
- Reset Answers button clears inputs mid-quiz
- Updated navigation menu on all pages
- Two new key concepts added (AiTM phishing, phishing-resistant MFA)
- Three new references added (CISA MFA guidance, Microsoft, OWASP)
- Code documented with comments throughout HTML, CSS, and JS

## Technologies
- HTML5 (semantic elements)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Vanilla JavaScript (ES6, no frameworks)
- GitHub Pages for deployment

## Requirements Met
- Six+ pages with a consistent 7-item main menu
- Headings, lists, images, tables, forms
- One external CSS file
- Element, class, ID, and attribute selectors
- Grid layout (main menu) and Flexbox layout (content, profile)
- Hover effects, padding, margins, borders, colors, fonts
- Footer note linking to the class website
